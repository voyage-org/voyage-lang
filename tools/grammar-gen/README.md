# grammar-gen

Not yet started, and not currently expected to be needed.

ADR-0010 decided `Voyage.Compiler`'s parser is hand-written recursive
descent, not generated from a grammar file — so there's no grammar
artifact for a tool in this directory to generate a parser *from*. This
placeholder exists for the canonical project-layout structure; if it
stays empty long-term, that's consistent with ADR-0010's decision, not a
gap.
